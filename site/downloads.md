## Quick reference

The quick reference is included in the main book before the problem chapters,
and its separate edition is four US Letter pages with two columns and
9-point body text. It covers notation, elementary formulas, calculus methods,
domain and convergence conditions, geometric measures, matrix and tensor
operations, and selected supporting identities. It is arranged for printing at
actual size, including as two double-sided sheets, or keeping open beside a problem.

## PDF and printing

You can print any reading page using your browser. The complete
[book](/generated/book) includes all solutions without disclosure
controls. The downloadable LaTeX source can be compiled with a TeX distribution.
The repository's PDF workflow compiles the complete current manuscript. Alpha
version tags publish a GitHub prerelease with the PDF attached. This includes
all material written for that edition. Each prerelease preserves a fixed edition for offline reading.
