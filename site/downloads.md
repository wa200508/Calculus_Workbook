## PDF and printing

You can print any reading page using your browser. The complete
[book](/generated/book) includes all solutions without disclosure
controls. The downloadable LaTeX source can be compiled with a TeX distribution.
The repository's PDF workflow compiles the complete current manuscript. Alpha
version tags publish a GitHub prerelease with the PDF attached. This includes
all material written for that edition. Each prerelease preserves a fixed edition for offline reading.
